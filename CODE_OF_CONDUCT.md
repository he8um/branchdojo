# Code of Conduct

BranchDojo is intended to help developers practice Git safely. Contributors and users are expected to interact respectfully and constructively.

## Expected Behavior

- Be respectful and direct.
- Assume good intent.
- Help beginners without condescension.
- Keep feedback specific and actionable.
- Prefer safe, deterministic, and maintainable solutions.

## Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Discriminatory language or behavior.
- Deliberately unsafe suggestions that could destroy user data.
- Publishing secrets, private prompts, or private development notes.

## Enforcement

Maintainers may remove comments, close issues, reject contributions, or block users who violate this code of conduct.
