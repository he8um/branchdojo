# Positioning

## Tagline

Practice real Git workflows in safe, disposable local repositories.

## Category

Local Git kata tool.

## Primary Differentiation

BranchDojo creates real repositories and validates final repository state. It is not a visualizer, not a GUI, not a cheat sheet, and not a guided trainer.

## Positioning Statement

For developers who know basic Git commands but lack workflow recovery practice, BranchDojo is a local Git kata tool that creates safe disposable repositories with prepared conflicts and mistakes. Unlike tutorials or visualizers, BranchDojo requires users to solve real Git states and validates the final result.

## Messaging Pillars

### Real Git, not simulation

BranchDojo uses actual Git repositories and actual Git commands.

### Safe by default

Exercises are disposable. BranchDojo refuses to operate on unknown or unsafe paths.

### Final-state validation

There can be multiple valid solutions. BranchDojo checks the resulting repository state, not a single command sequence.

### Beginner-friendly but not childish

Output should be clear and actionable, but the tool should still feel like a professional developer utility.

## Public Description

BranchDojo is a local CLI that generates safe disposable Git repositories for practicing real workflow recovery: merge conflicts, bad commits, wrong-branch work, and more.
