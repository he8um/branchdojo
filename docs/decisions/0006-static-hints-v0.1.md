# ADR 0006: Static Hints in v0.1

## Status

Accepted for v0.1.

## Context

Progress-aware hints require partial-state analysis and could blur the line between kata tool and guided trainer.

## Decision

BranchDojo v0.1 provides static hints per exercise.

## Consequences

Hints are simple, predictable, and easy to document. Progress-aware hints are deferred to v0.2.
