# ADR 0005: No Existing Repository Support in v0.1

## Status

Accepted for v0.1.

## Context

Operating on real user repositories increases safety risks and expands the product scope.

## Decision

BranchDojo v0.1 only creates and manages disposable generated repositories.

## Consequences

The product is safer and easier to explain. Existing repository support can be reconsidered later with stronger safeguards.
